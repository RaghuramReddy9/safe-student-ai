#  Safe Student AI Assistant

A Gemini-powered educational chatbot that filters toxic or biased messages using Google's Perspective API before responding.

##  Live Demo
[Open App on Streamlit](https://safe-student-ai.streamlit.app)

##  Features
- Real-time toxicity detection (Perspective API)
- Configurable safety slider
- Gemini 1.5 Flash for educational answers
- Conversation logging (CSV)
- Deployed on Streamlit Cloud

##  Tech Stack
Python · Streamlit · Google Generative AI SDK · Perspective API · Pandas

##  Run Locally
```bash
pip install -r requirements.txt
streamlit run app.py
```
